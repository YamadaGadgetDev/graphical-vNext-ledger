Video Metadata JSON API

AUTH_MODE=apikey（ランディングは公開 / APIは /v1 配下でAPIキー必須）

使い方

POST /v1/metadata にURL等を送ると、解析済みメタデータをJSONで返します。

curl -sS -X POST https://YOUR-DOMAIN/v1/metadata \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"url":"https://www.youtube.com/watch?v=..."}'

ステータス

GET / は公開ランディングです。GET / に Accept: application/json を付けると簡易ヘルスを返します。
